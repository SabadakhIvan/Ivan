# Моделювання DoS-атаки на вузол мережі

Проєкт реалізує імітаційну модель роботи мережевого вузла у двох режимах:
1. штатний режим;
2. режим DoS-атаки з підвищеною інтенсивністю вхідних запитів.

## Склад проєкту
- `main.py` — стартовий файл запуску;
- `dos_attack_simulator.py` — основна логіка моделі;
- `demo_config.json` — демонстраційні параметри моделювання;
- `requirements.txt` — залежності;
- `outputs/` — результати моделювання.

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

Або із зазначенням власного конфігураційного файлу:
```bash
python main.py --config demo_config.json --output-dir outputs
```

## Що формує програма
Після запуску створюються:
- `request_dynamics.png` — динаміка надходження та обробки запитів;
- `queue_waiting.png` — черга та умовний час очікування;
- `dropped_requests.png` — кількість відхилених запитів;
- `dos_report.txt` — підсумковий звіт.
